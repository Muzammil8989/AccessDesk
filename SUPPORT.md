# Getting help

## Where to ask

| I want to...                        | Go here                                                                     |
| ----------------------------------- | --------------------------------------------------------------------------- |
| Ask how to set up or use AccessDesk | [Discussions](../../discussions) (or an issue if Discussions is turned off) |
| Report a bug                        | [Open a bug report](../../issues/new?template=bug_report.md)                |
| Suggest a feature                   | [Open a feature request](../../issues/new?template=feature_request.md)      |
| Report a security problem           | **Privately**. See [SECURITY.md](SECURITY.md). Never open a public issue.   |
| Report unacceptable behavior        | See [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md)                                |
| Contribute code or docs             | Read [CONTRIBUTING.md](CONTRIBUTING.md)                                     |

## Before you ask

1. Read the [README](README.md), including the Troubleshooting section, and [docs/development.md](docs/development.md).
2. Search the existing issues. Your question may already have an answer.
3. Remove tokens, passwords and personal data from any logs or screenshots you share.

AccessDesk is maintained by volunteers. Replies may take a few days.
